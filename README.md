# Full Calendar Plugin (Fork)

Personal fork of [obsidian-community/obsidian-full-calendar](https://github.com/obsidian-community/obsidian-full-calendar) adding a [retend](https://retend.io) calendar backend. This allows Full Calendar to read and write `.retend` schedule files stored in your vault.

For the original plugin, documentation, and issue tracker, see the [upstream repository](https://github.com/obsidian-community/obsidian-full-calendar).
