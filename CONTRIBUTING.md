Keyboard Calendar is open to contributions!

- You can build the plugin for development by running `npm run dev`.
- The [hot reload plugin](https://github.com/pjeby/hot-reload) makes development a lot easier.

To start getting familiar with the codebase, read the [architecture guide](src/README.md).

Before releasing a mobile-visible calendar change, verify the main Week view and Day Calendar drawer on both iOS and Android in portrait and landscape. Confirm that horizontal week swipes, long-press selection, event drag/resize, date and event opening, toolbar wrapping, rotation, and reopening after two app restarts all preserve the expected date and note contents.
